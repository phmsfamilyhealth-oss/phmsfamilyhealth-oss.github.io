ยังไม่ได้เลือกบุคคล

ไฟล์ละไม่เกิน 10 MB — ยังไม่อัปโหลดจริง

หากไม่มีรายชื่อแพทย์ สามารถระบุชื่อสำหรับนัดนี้หรือข้ามได้

🏥 ข้อมูลโรงพยาบาลเพิ่มเติม
🩺 เรื่องที่ติดตามรักษา

รายละเอียดที่กรอกเองยังไม่ถือว่าแพทย์ยืนยัน

🚗 สิทธิรักษาและการเดินทาง
🚶 เหตุผลที่ไปโดยไม่ได้นัด
📋 ผลหลังพบแพทย์ (จากข้อมูลที่มี)

บันทึกตามข้อมูลจริง ไม่ถือเป็นผลที่แพทย์ยืนยันโดยอัตโนมัติ

🔗 เชื่อมนัดเดิม (ทดลองอ่านข้อมูลจริง)

เลือกรายการนัดเดิมของบุคคลนี้เท่านั้น ข้อมูลความสัมพันธ์ยังไม่ถูกบันทึก

เลือกบุคคลก่อนค้นหานัดเดิม

☎️ ติดต่อโรงพยาบาลและเลื่อนนัด (อ่านข้อมูลจริง)

ติดต่อเพื่อขอเลื่อนนัดได้ แต่ระบบจะไม่เปลี่ยนวันนัดเดิมจนกว่าโรงพยาบาลจะยืนยัน

ยังไม่ได้โหลดข้อมูลติดต่อ

การเลือกสถานะนี้ยังไม่เปลี่ยนวันนัดหรือบันทึกข้อมูลในระบบ

เอกสาร งานมอบหมาย และแจ้งเตือนยังรอ API ตรวจสิทธิ์ จึงยังไม่เปิดการบันทึก

ตั้งชื่อสั้น ๆ เพื่อให้รู้ว่าไปโรงพยาบาลเรื่องอะไร

ข้อมูลที่ผู้ใช้แจ้งเอง ยังไม่ใช่การวินิจฉัยจากแพทย์ และยังไม่บันทึกในโหมดทดลอง

เตรียมแล้ว 0/0 รายการ

ชื่อโรงพยาบาล แผนก และแพทย์จะเติมอัตโนมัติจากทะเบียนที่ตรวจสอบแล้ว หากยังไม่มีชื่อแพทย์ในทะเบียน สามารถบันทึกนัดโดยไม่ระบุแพทย์ได้เมื่อเปิดระบบจริง
